##  DEMO SCRIPT - STANDARD DEMO (15 minutes)

### **PART 1: Introduction (1 minute)**

"We're about to see the NITTE Merchandise Shop - a production-ready microservices system with 3 tiers:
1. **Node.js API Gateway** (port 3000) - Handles HTTP requests, authentication, routing
2. **Python FastAPI Service** (port 8000) - Business logic, database queries
3. **MongoDB** (port 27017) - Persistent data storage

All running in Docker containers, ready to scale to Kubernetes."

### **PART 3: Products Management (5 minutes)**

#### Step 1: Get existing products
```bash
curl -X GET http://localhost:3000/api/products | jq .
```

**Explanation:** "This calls the Node.js Gateway, which proxies to the Python service, which queries MongoDB."

---

#### Step 2: Create a new product
```bash
curl -X POST http://localhost:3000/api/products \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Limited Edition Merch",
    "description": "Exclusive NITTE merchandise",
    "price": 999.99,
    "category": "premium",
    "stock": 50
  }' | jq .
```

**Expected response:**
```json
{
  "_id": "507f1f77bcf86cd799439011",
  "name": "Limited Edition Merch",
  "description": "Exclusive NITTE merchandise",
  "price": 999.99,
  "category": "premium",
  "stock": 50,
  "createdAt": "2026-03-14T10:30:00.000Z"
}
```

**Say:** "Notice the `_id` was auto-generated by MongoDB. The product is now in the database."

---

#### Step 3: Get a specific product
```bash
# Replace with actual product ID from above
PRODUCT_ID="507f1f77bcf86cd799439011"

curl -X GET http://localhost:3000/api/products/$PRODUCT_ID | jq .
```

**Expected:** Returns the product we just created

---

#### Step 4: Update the product
```bash
curl -X PUT http://localhost:3000/api/products/$PRODUCT_ID \
  -H "Content-Type: application/json" \
  -d '{
    "price": 1299.99,
    "stock": 75
  }' | jq .
```

**Say:** "We just updated the price and stock. The change is immediately reflected in MongoDB."

---

#### Step 5: Delete the product
```bash
curl -X DELETE http://localhost:3000/api/products/$PRODUCT_ID | jq .
```

**Expected response:**
```json
{
  "message": "Product deleted successfully"
}
```

### **PART 5: Architecture Demonstration (2 minutes)**

**Show the architecture:**
```bash
cat <<'EOF'

┌─────────────────────────────────────────────────────────┐
│                   CLIENT REQUEST                         │
│              curl http://localhost:3000                  │
└────────────────────────┬────────────────────────────────┘
                         │
                         ▼
        ┌────────────────────────────────┐
        │   Node.js Express Gateway      │
        │   (port 3000)                  │
        │  - Authentication              │
        │  - Rate limiting               │
        │  - Request routing             │
        │  - Prometheus metrics          │
        └────────────┬───────────────────┘
                     │
                     │ Internal HTTP call
                     │ http://python-service:8000
                     │
                     ▼
        ┌────────────────────────────────┐
        │   Python FastAPI Service       │
        │   (port 8000)                  │
        │  - Business logic              │
        │  - Data validation             │
        │  - Prometheus metrics          │
        └────────────┬───────────────────┘
                     │
                     │ Async Driver (Motor)
                     │ mongodb://mongodb:27017
                     │
                     ▼
        ┌────────────────────────────────┐
        │   MongoDB Database             │
        │   (port 27017)                 │
        │  - Products collection         │
        │  - Orders collection           │
        │  - Users collection            │
        └────────────────────────────────┘

Flow: Client -> Node.js -> Python -> MongoDB -> Back up the chain
Time: Typically < 100ms roundtrip

EOF
```

**Explain:**
- "All communication is over HTTP/TCP"
- "Each layer can be scaled independently"
- "Python is async for high concurrency"
- "MongoDB stores documents (JSON-like)"

## 🚨 TROUBLESHOOTING

**If services aren't responding:**
```bash
# Restart all services
docker compose restart

# Check logs
docker logs nitte-node-backend
docker logs nitte-python-service
docker logs nitte-mongodb

# Verify network
docker network ls
docker network inspect docker_nitte-network
```

**If MongoDB is "unhealthy":**
```bash
# This is normal - it's just a health check issue, MongoDB is working
# You can verify:
curl http://localhost:3000/api/products
# If it returns data, MongoDB is fine
```

**If port is already in use:**
```bash
# Find what's using the port
lsof -i :3000
# Kill it or use different port in .env
```

**Clear all data and restart:**
```bash
docker compose down -v
docker compose up -d
# All data is cleared, fresh start
```
